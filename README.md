# PULSE AI 

## Descripción
PULSE AI es una suite tecnológica de inteligencia artificial enfocada en el bienestar académico de los estudiantes.

El proyecto integra un asistente virtual, un modelo predictivo y una herramienta de análisis de texto.

## Objetivo
Desarrollar una herramienta tecnológica que permita analizar algunos factores relacionados con el bienestar académico mediante programación, Machine Learning y procesamiento de lenguaje natural.

## Módulos

### 1. Asistente virtual
Desarrollado con HTML, CSS y JavaScript. Permite interactuar con el usuario y consultar información relacionada con estrés, sueño, tareas y carga académica.

### 2. Modelo predictivo
Desarrollado en Python utilizando Machine Learning. Analiza datos simulados como horas de sueño, horas de estudio, carga académica, recuperación y actividad física.

### 3. Análisis de texto
Utiliza procesamiento de lenguaje natural para identificar palabras frecuentes en comentarios de estudiantes.
